# GPT-SoVITS

It is optimized with Apple Silicon, runs fast.

It is trained with about 2500 hours of Chinese and 1500 hours of English. The generated speech has slight Chinese accent.

# Raon-OpenTTS

Great for English, but at least twice slower than GPT-SoVITS. It takes about 2 minutes to generate a 1 minute long audio.

# Pictory

One can generate Avatar there with voice cloned. The audio quality is great. However, the speech generated has slight Indian accent.
